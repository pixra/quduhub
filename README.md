### 🌌 About QuduHub

> **The workspace where ideas take shape.**

**[QuduHub](https://qudu.in)** (also referred to as Qudu) is a **General-Purpose AI Workspace** developed under **[Pixra Global](https://github.com/pixra)**. Uniting conversational intelligence, deep research, and digital creation into one focused environment, Qudu serves as the ultimate workspace for writers, engineers, researchers, and students alike. 

Currently in **Pre-Launch Preview**, the platform is actively evolving with advanced agentic workflows and commerce integrations in active development.

<br>

### ⚙️ Core Modules & Capabilities

*   🧠 **[Qudu AI Assistant (/chats)](https://qudu.in/ai):** A multi-turn conversational interface equipped with markdown rendering, interactive architecture diagrams (Mermaid), and in-browser code execution (Sandpack). 
*   🗂️ **Universal Document Viewer:** Seamless side-by-side tab management for code files, markdown, and visual media within the workspace.
*   🛒 **Qudu Shop Discovery (Experimental):** An early catalog browsing preview featuring AI-powered merchant recommendations.
*   📚 **Syllabus Study Modules (Legacy):** University course notes, PYQs, and educational archives actively supporting tested departments.
*   ⚙️ **In Active Development:** Autonomous agentic workflows, multi-step external tool execution, persistent background tasks, and real-time live merchant integrations.
